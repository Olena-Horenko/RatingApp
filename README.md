# Система формування рейтингу студентів

Настільний застосунок для обробки Excel-журналу успішності,
формування рейтингу та попередньої перевірки критеріїв стипендії.

## Можливості
- завантаження Excel-журналу (.xlsx)
- вибір навчальної групи
- розрахунок рейтингу та перевірка академічних боргів
- експорт результатів в Excel

## Вимоги
- Python 3.10+

## Розгортання
git clone https://github.com/Olena-Horenko/RatingApp.git
cd student-rating-app
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
